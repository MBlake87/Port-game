# 🔌 Port Matching Game

A simple, fast, and fun web-based quiz game where you match **network port numbers** to their correct **protocol descriptions**.  
Built with **React + Vite**, deployed on **Vercel**, and designed as a lightweight learning tool for IT Support, Networking, and Cybersecurity fundamentals.

---

## 🚀 Live Demo

👉 **Play the game here:** https://port-game.vercel.app/

---

## 🎮 Features

- 🔀 Randomised questions every round
- 🔢 Multiple-choice answers (4 options per question)
- 👍 Correct / ❌ Incorrect feedback
- ➡️ Skip / Next button
- 📈 Score tracking
- 📱 Fully responsive layout
- 🧠 Uses a curated dataset of common industry-standard ports

---

## 🧱 Tech Stack

- **React** (Vite)
- **JavaScript**
- **CSS** (custom styles, no frameworks)
- **Vercel** (deployment)
